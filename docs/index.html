Quick start — 60 seconds, no hardware

Python 3 is all you need. Each command ends with a proof line — compare yours; they must match.

git clone <your-fork-url> blinker-to-riscv
cd blinker-to-riscv
python3 sim/test_golden_model.py   # RESULT: 26 passed, 0 failed
python3 sim/check_rtl.py           # ALL RTL STRUCTURAL CHECKS PASSED
python3 fw/generate_hex.py         # FIRMWARE HEX VERIFIED (x8=31, x10=143)

The journey — 24 steps, one change at a time

  1. Blink. Count on LEDs. Learn clocks, Verilog, and the reset button you press with a finger.
  2. Slow down. A clock divider (gearbox) makes megahertz visible to human eyes.
  3. Remember. Patterns from memory + a program counter: the seed of every CPU.
  4. Decode. Teach the design to recognize 11 RISC-V instruction classes and 5 immediate formats.
  5. Compute. Register file + state machine + ALU: read two numbers, compute, write one back.
  6. Jump & branch. Loops, function calls, and all six conditions — now it can decide.
  7. Reach far. Big constants, byte/half/word memory, masks and sign extension.
  8. Talk. LEDs and a serial port appear as addresses; the CPU prints Hello.
  9. Grow up. Fixed-point Mandelbrot, multiply routine, compiled C, flash execute-in-place.

How the CPU works — five questions

Where is the instruction? How is it understood? Where are the numbers? What computes? How does it reach the world? Answer those and you can read any processor.

🔢 Program counter

Byte address of the current instruction; +4 each step, or a jump/branch target.

🔍 Decoder

7-bit opcode + function codes + immediates in R/I/S/B/U/J formats.

🗄️ Registers

32 numbers, two read per cycle; x0 is always zero.

🧮 ALU

One shared subtract does math, compares, and branches; one shifter does all shifts.

🚌 Bus

Top address bits choose RAM, devices (LEDs/UART), or flash. One polite rule: wait when memory is busy.

💾 Memory map

00 RAM · 01 devices (one-hot) · 10 SPI flash execute-in-place.
